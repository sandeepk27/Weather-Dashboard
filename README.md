# Weather-Dashboard

This is a simple Weather Application that provides real-time weather information for your location. It displays:

1. The current day's temperature in Celsius.
2. A 5-day weather forecast temperatures in Celsius.

The application uses weather data from a public API and offers a user-friendly interface for a seamless experience.

Fully functional on desktop and mobile devices.

Clone the Repository:

git clone https://github.com/sandeepk27/Weather-Dashboard.git

cd weather-Dashboard

The application will be available at http://localhost:3000 using index.html.
